# Screenshots

This folder contains screenshots demonstrating the key features and functionality of the **AI-Powered Job Recruitment System** built on the Salesforce Lightning Platform.

## Screenshot List

### 1. Home Page (`home-page.png`)

Displays the application's home page with navigation and recruitment overview.

### 2. Lightning App (`lightning-app.png`)

Shows the custom Salesforce Lightning application used for recruitment management.

### 3. Candidate Application (`candidate-application.png`)

Illustrates the Candidate Application object with candidate details, application status, approval status, and AI Candidate Score.

### 4. Job Opening (`job-opening.png`)

Displays the Job Opening object used to manage available positions, required skills, and hiring information.

### 5. Flow Builder (`flow-builder.png`)

Shows the Salesforce Flow responsible for automating recruitment processes such as notifications and record updates.

### 6. Approval Process (`approval-process.png`)

Demonstrates the approval workflow used for reviewing and approving candidate applications.

### 7. Reports (`reports.png`)

Displays recruitment reports that provide insights into candidate applications, approval status, and hiring progress.

### 8. Dashboard (`dashboard.png`)

Shows interactive dashboards with visual charts and recruitment analytics.

### 9. Agentforce (`agentforce.png`)

Illustrates the Agentforce AI assistant used to provide candidate summaries, hiring recommendations, and AI-powered recruitment insights.
