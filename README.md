# AI-Powered Job Recruitment System

A Salesforce Admin project that streamlines recruitment using custom objects, Flow Automation, Approval Processes, Reports, Dashboards, and Agentforce.

## Features
- Candidate Application Management
- Job Opening Management
- Flow Automation
- Approval Process
- Reports & Dashboards
- Agentforce AI Assistant

## Tech Stack
- Salesforce Lightning
- Flow Builder
- Approval Processes
- Reports & Dashboards
- Agentforce
